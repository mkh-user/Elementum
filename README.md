# Welcome to the Elementum III Project!

Dive into the world of Elementum III, a powerful plugin designed to enhance your Godot 4 experience by seamlessly downloading and managing additional features—no new plugins or plugin managers required!

## What is Elementum?
Elementum is your new best friend in the Godot ecosystem! This intuitive plugin integrates effortlessly into the bottom panel of your editor, presenting you with a curated list of diverse tools hosted on ElementumHost. With just a single click, you can download these tools, and Elementum will automatically install them, making them ready for action in no time!

## What does Elementum offer?
Elementum currently supports three exciting types of assets: nodes, classes, and libraries.

### Nodes
When you download nodes through Elementum, they are added as fresh classes in the add node section of your editor. These nodes are expertly managed by a script that Elementum introduces, ensuring that new nodes are easily accessible to developers like you. 

### Classes
Enhance your projects with the power of classes! Elementum automatically introduces these classes to your editor, simplifying the process of extending functionality. All you need to do is let the plugin detect and download them.

### Libraries
One of Elementum's standout features is its libraries—collections of functions that you can use without instantiation. Unlike traditional classes, you don’t need to create an instance to access non-static library functions; Elementum makes them available as Autoload, streamlining your workflow.

## Receiving elements
Getting started with Elementum assets is a breeze! Simply download the latest version from the releases, head over to your editor, and select the downloaded file in the AssetLib section via the Import option. Next, navigate to the Plugins tab in your project settings and activate Elementum. Voila! A panel will magically appear at the bottom of your editor, ready for you to explore and acquire assets. Just click on your desired asset, confirm, and watch as everything falls into place!

## Element sharing
Want to share your creations with the world? Head over to [ElementumHost](https://github.com/mkh-user/ElementumHost) and create an issue using the Upload Element template ([fast link](https://github.com/mkh-user/ElementumHost/issues/new?template=upload-element.md)). The template provides all the details you need to get started.

Once your element is approved, we’ll add it to the host and update the elements list. Please note that after each update, it may take a little while for the changes to be reflected in the plugin due to a minor glitch in the display. Sometimes, it might take up to an hour for everything to sync perfectly.
